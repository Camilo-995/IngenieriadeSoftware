==================================================
INSTRUCCIONES DE INSTALACIÓN Y EJECUCIÓN
==================================================

Requisitos:
- Servidor Web Apache2.4 o superior.
- PHP 8.0 o superior activado en Apache.

Pasos para ejecutar:
1. Descomprimir el contenido de este archivo .zip.
2. Copiar la carpeta del proyecto dentro del directorio raíz de Apache (ej. C:\Apache24\htdocs\).
3. Asegurarse de que el servidor Apache esté en ejecución.
4. Abrir el navegador e ingresar a la ruta: http://localhost:80/index.html

*Nota: Este proyecto es completamente autónomo y no requiere de configuración de bases de datos ni dependencias externas.
